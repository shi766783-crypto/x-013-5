# 宠物家 Petcare Home

家庭宠物健康与日程管家，基于 Vue 3 + Vite 构建，纯前端运行。

## 本地运行

```bash
npm install
npm run dev
```

## 已包含

- 宠物档案：种类、品种、性别、出生日期、年龄、体重、绝育、芯片号和照片
- 健康指标：体重、体温、心率记录，Canvas 趋势图和正常范围提示
- 疫苗与驱虫：下次日期和提前 7 天提醒
- 用药、喂食、活动记录，以及每日清单和本周活动统计
- 用药疗程：剩余天数与疗程进度条，结束前 3 天提醒停药/复诊，疗程结束自动移出当日用药；支持调整日期延长疗程或一键提前结束，提醒随日期实时变化；进行中/未开始/已结束状态统一计算，已结束疗程不会被误判为进行中
- 家庭看板、12 项成就徽章、健康榜单
- `localStorage` 本地持久化，不依赖后端

首次打开会载入一组演示数据，新增或修改的数据会自动保存到当前浏览器。
